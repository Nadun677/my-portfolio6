# 💻 Personal Portfolio — Nadun Konara

A modern and responsive personal portfolio website created to showcase my skills, projects, education, experience, and software development journey.

The portfolio is designed with a clean and professional dark-themed interface, smooth animations, responsive layouts, and interactive components.

- 🏠 Modern Hero Section
- 👨‍💻 About Me Section
- 🛠️ Categorized Skills Section
- 🚀 Projects Showcase
- 📄 View & Download CV

- 🎨 Colorful Technology Icons
- ✨ Smooth Hover Animations
- 📱 Fully Responsive Design
